# Motorola Retail Analytics & Transaction Intelligence Dashboard

An interactive **Power BI dashboard** built to analyze Motorola retail sales, transaction performance, customer ratings, and regional trends. The project transforms sales data into actionable insights through interactive filters and visual analytics.

## 📊 Dashboard Overview

The dashboard provides a consolidated view of key retail performance indicators:

- **Total Sales:** 68M
- **Total Quantity Sold:** 2K
- **Total Transactions:** 325
- **Average Order Value:** 42K

*Metrics represent the overall dashboard values before applying filters.*

## 🚀 Key Features

- **Regional Sales Analysis:** Visualizes city-wise sales performance across locations such as Delhi, Mumbai, Hyderabad, and Bengaluru.
- **Monthly Sales Trends:** Tracks monthly quantity trends to explore changes in sales performance over time.
- **Customer Ratings Analysis:** Examines customer rating patterns to understand customer satisfaction.
- **Payment Method Analysis:** Compares transactions across Debit Card, Credit Card, Cash, and UPI.
- **Brand Performance Comparison:** Analyzes sales and quantity across brands, including Apple, OnePlus, Samsung, Vivo, and Xiaomi.
- **Mobile Model Analysis:** Compares sales performance across different mobile models.
- **Interactive Filtering:** Enables users to explore data by month, mobile model, payment method, brand, and day of the week.
