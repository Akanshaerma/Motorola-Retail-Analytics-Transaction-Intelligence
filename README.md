# Motorola Mobile Sales & Regional Analytics Dashboard

An interactive Power BI dashboard designed to analyze smartphone sales, regional distribution, customer ratings, and transaction trends for Motorola retail data.

## 📊 Dashboard Overview
* **Theme & Branding:** Custom Motorola corporate blue design integrated with side navigation panels and dynamic month-wise filtering.
* **Key Metrics Tracked:** Total Sales (68M), Total Quantity (2K), Total Transactions (325), and Average Order Value (42K).

## 🚀 Key Features
* **Geospatial City Analysis:** Interactive map mapping total sales across major cities like Delhi, Mumbai, Hyderabad, and Bengaluru.
* **Customer & Payment Intelligence:** Visual breakdown of customer satisfaction ratings alongside payment method distribution (Debit Card, Cash, UPI, Credit Card).
* **Temporal & Brand Performance:** Day-wise trend line analysis alongside multi-brand comparisons including Apple, OnePlus, Samsung, Vivo, and Xiaomi.

## 🛠️ Tools & Technologies Used
* **Power BI Desktop**
* **DAX** for custom metrics and aggregation
* **Data Modeling & Map Visuals**
